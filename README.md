## איך מעדכנים תוכן (מהטלפון)

### ממשק ניהול (מומלץ)
נכנסים ל-`https://yaronlasko.github.io/Standard14/admin.html` מהטלפון ומעדכנים הכל בטפסים:
הודעות (עם שליחה לוואטסאפ בלחיצה), מטלות, צילום לו״ז, חברי צוות, קישורים וצוותים חדשים.
כל שמירה מתעדכנת באתר תוך כדקה-שתיים.

**כניסה בפעם הראשונה:** צריך משתמש GitHub עם הרשאה למאגר ו"מפתח גישה" (Token). ההוראות המלאות מופיעות במסך הכניסה.
כדי לתת למישהו אחר לנהל: Settings ← Collaborators ← Add people ← שם המשתמש שלו ב-GitHub.
אחרי שהוא מאשר את ההזמנה, הוא יוצר מפתח משלו לפי ההוראות במסך הכניסה.

### עריכה ידנית
כל התוכן נמצא בקבצים בתיקייה `data/`. **אין צורך לגעת בקוד.**

**דרך 1:** לפתוח סשן של Claude Code ולכתוב בעברית מה לעדכן, למשל
"תוסיף הודעה דחופה: מחר השכמה ב-5:00" או "תוסיף מטלה עם תג״ב ליום חמישי".

**דרך 2: עריכה ישירה ב-GitHub:** נכנסים לקובץ בדפדפן ← אייקון העיפרון ✏️ ← עורכים ← Commit changes.
אחרי כשתי דקות האתר מתעדכן לבד.
אם נשבר משהו בקובץ (פסיק או מרכאה חסרים), הבדיקה האוטומטית תיכשל והאתר לא יתעדכן, כך שהגרסה הקודמת נשארת באוויר.

### הודעה
```json
{
  "id": "shabbat-exit",
  "date": "2026-11-20T09:00",
  "title": "יציאה לשבת",
  "body": "היציאה ב-12:00 מהשער הראשי.\nלהביא נשק ומחסניות.",
  "level": "important",
  "pinned": false,
  "author": "מפקד הצוות",
  "expires": "2026-11-21"
}
```
- `level`: אפשר להשמיט (הודעה רגילה), `"important"` (חשוב, כתום) או `"urgent"` (דחוף, אדום)
- `pinned: true`: ההודעה נעוצה למעלה
- `expires`: אחרי התאריך הזה ההודעה נעלמת לבד (לא חובה)
- `\n` = ירידת שורה. קישורים בטקסט הופכים ללחיצים אוטומטית

### חבר צוות
```json
{ "name": "ישראל ישראלי", "role": "צוער", "phone": "050-1234567" }
```
הכפתור הירוק פותח שיחת וואטסאפ. אפשר להוסיף `"photo": "files/israel.jpg"`.

### מטלה
```json
{
  "id": "tactical-brief-1",
  "title": "פקודת מבצע",
  "due": "2026-11-27T18:00",
  "description": "כתיבת פק״מ לפי התבנית.",
  "checklist": ["לקרוא את התבנית", "לכתוב טיוטה", "להגיש למפקד"],
  "materials": [
    { "title": "תבנית פק״מ", "url": "https://drive.google.com/..." }
  ]
}
```
- `id`: מזהה ייחודי באנגלית בלי רווחים. **לא משנים אותו אחרי פרסום** (הסימונים בצ׳ק ליסט נשמרים לפיו)
- `due` (תג״ב): `2026-11-27` או עם שעה `2026-11-27T18:00`
- הסימונים בצ׳ק ליסט נשמרים בטלפון של כל צוער בנפרד

### לו״ז
שתי אפשרויות, ואפשר להשתמש בשתיהן יחד (מופיע מתג בין "יומן" ל"תמונה"):

**Google Calendar:** ביומן גוגל ← הגדרות היומן ← "הרשאות גישה" ← לסמן "פרסום לציבור".
אחר כך ב"שילוב היומן" מעתיקים את **מזהה היומן** (Calendar ID) ומדביקים:
```json
"googleCalendar": { "calendarId": "xxxxxxxx@group.calendar.google.com" }
```
**צילום:** מעלים תמונה לתיקייה `files/` (ב-GitHub: Add file ← Upload files) ומעדכנים:
```json
"images": [ { "src": "files/week-47.jpg", "caption": "לו״ז שבוע 47" } ]
```

## הוספת צוות נוסף
1. מעתיקים את התיקייה `data/teams/team-14` לתיקייה חדשה, למשל `data/teams/team-15`
2. מוסיפים ב-`data/site.json` לרשימה `teams`: `{ "id": "team-15", "name": "צוות 15" }`

מרגע שיש יותר מצוות אחד מופיעה בראש האתר בחירת צוות, ואפשר לשלוח קישור ישיר: `?team=team-15`.
הודעות וקישורים כלליים (ברמת פלוגה או גדוד) נכתבים ב-`data/announcements.json` וב-`data/links.json` ומופיעים אצל כל הצוותים.
